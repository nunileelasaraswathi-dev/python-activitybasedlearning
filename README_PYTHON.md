## Project Overview

This project contains ten programming problem statements focused on
validation, calculations, simulations, and decision-making. Each problem
can be implemented in Python using input validation, conditional
statements, loops, lists, and functions.

## Problem Statements

### 11\. Examination Result and Grace-Mark Validation

Process marks across multiple subjects, apply subject-wise pass criteria
and a specified grace-mark policy, and generate final classifications
without exceeding maximum marks.

### 12\. Attendance Recovery Computation

Calculate current attendance percentages and determine the minimum
consecutive classes required to reach an eligibility threshold under
different future attendance scenarios.

### 13\. ATM Transaction Sequence Simulation

Process a sequence of deposits and withdrawals, maintain a simulated
balance, enforce withdrawal limits, reject invalid transactions, and
produce a transaction summary.

### 14\. Warehouse Inventory Reconciliation

Compare opening stock, incoming quantities, dispatched quantities, and
closing stock across multiple products; detect discrepancies and
calculate replenishment requirements.

### 15\. Smart Parking Fee Management

Calculate charges from entry and exit times, vehicle categories,
overnight parking, daily limits, and penalty conditions while validating
time inputs.

### 16\. Multi-Day Water Tank Simulation

Process changing inflow and outflow quantities, update water levels,
detect overflow and shortages, and determine the first interval in which
the tank reaches a specified threshold.

### 17\. Student Performance Trend Analysis

Compare assessment scores across multiple examinations, calculate
improvements and declines, identify consistently weak subjects, and
classify students according to defined criteria.

### 18\. Fuel Consumption and Route Comparison

Calculate fuel requirements and journey costs for several vehicles using
distance, mileage, fuel prices, and reserve requirements; identify the
lowest-cost feasible option.

### 19\. Multi-Product Shopping Budget Constraint

Evaluate a shopping basket containing multiple products and quantities,
apply discount conditions, and determine which purchases must be reduced
to remain within a fixed budget.

### 20\. University Admission Decision Engine

Evaluate candidates using subject eligibility, aggregate marks,
course-specific thresholds, and tie-breaking criteria; generate a ranked
list of eligible applicants.
